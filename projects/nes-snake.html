NES Snake

Description

During the course Retro Programming our assignment was to create a game for the NES in 6502 assembly. We were not allowed to use any C, even though our compiler supported it.
Since the NES at Howest had the four player adapter accessory, we wanted to make use of it.
We choose to make a snake battle royale as it seemed like a simple enough game, but with an interesting twist.

Memory limitations

To deal with memory limitations we precisely managed where each bit had to go. This meant we had a lot of memory left at the end of our journey; but that was a price worth paying.
Memory management alone was not our only concern, we only have a limited amount of time we can render to the screen each frame. We also calculated how much time we had for this.

Technologies

  • 6502 Assembly
  • Alchemy65 for running and debugging NES games
  • Mesen-X as the emulator as it has the required lua support for debugging with Alchemy65
  • cc65 as the compiler and linker since it could generate .NES files for us

My contributions

My first contribution was creating the GitHub template that a number of groups ended up using. Along with this came a lot of research on which tools we would use.
After that I spend some time researching how the four-score controller worded and created co-routines to fetch controller input.
For the game itself, my main task was everything to do with the player: movement, and changing sizes.
Lastly, for this project I did take on the role of project manager.
