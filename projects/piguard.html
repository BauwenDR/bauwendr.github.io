PiGuard

Description

PiGuard is a smart doorbell prototype we made during the course called "The Lab" at KdG. This course can be compared to a gradwork, however this project is usually done in groups of three.
For this project we ended up using a Raspberry Pi along with OpenCV. The initial goal was to regonise and identify people and cars. Out of these two we only got the recognition and identification of people done.

A huge focus for us was the privacy aspect. We did not want to store any private information in our back-end. We ended up finding a solution where we only needed to store Family member names, events and their encrypted pictures on the back-end.
We accomplished this by encrypting the images in the request we send to back-end using a key that was agreed upon when initializing the doorbell.
This also meant we could keep the images of family members and past events on the Raspberry Pi. Every time it regonised someone it saved the image, it would try to regonise the person and if it failed to find the correct match, users could correct this in the app. Thus strengthening the recognition. For the training we would ask the user to upload a quick 30 second recording of the person so that the doorbell has some data to work with.

Technologies

  • React Native application for both Android & iOS
  • C++ app running on the doorbell using OpenCV to detect and recognise faces
  • Spring app running on the doorbell to handle the initial doorbell setup
  • Spring back-end managing all Users accounts' and their connected doorbells
  • Firebase for sending notifications to users

My contributions

My main contributions were all on the Raspberry Pi side. As the only dev that was comfortable using C++ that was fully my task.
This means I implemented the OpenCV facial recognition, all communication from the Raspberry Pi to the back-end, and the managing of training data.
Since I was already focused on the embedded side of the project, I also programmed the Kotlin app for the setup process.
