Arduino Wordl

Description

At KdG we had a 6 week embedded devices course. The exam assignment was to create a game for the Arduino. I went ahead and did a little extra adding a functioning UI written in Java + JavaFX that can communicate between the Arduino and a PC.
One of the limitations for this course was that we were not allowed to use "Arduino.h", so we had to create our own IO and utilities libraries.

In order to accomplish this I used a Java library to interact with a serial port (the USB cable to an Arduino is running in Serial Mode). The communication between the two devices uses a very simple, but functional communication protocol that I designed myself.

Memory limitations

An Arduino is also a device with little storage (compared to a modern PC). The game can also run in text only mode where the Arduino will relay information via the debug terminal in the IDE.
Because this is a lot of text and C stores strings in RAM by default, I had to implement a way for strings to be fetched from the much larger ROM instead.
